# Instrument defect: quilt-ewitness — stale duplicate `src/witness.mjs` breaks both experiment runners

Found: 2026-09-30 ~17:10 AKDT, by Lucineer (verification pass after selftrain-scout round 3 flagged it).
Repo HEAD at verification: `61b9e0403f2254691570cdf877bbbf81624df1f1` ("quilt-ewitness v0.1.0 ... 7/7 tests", 2026-09-30 09:25 UTC).
Fresh clone: `~/projects/quilt-ewitness-readonly`.

## Verified defects (all reproduced hands-on)

1. **`src/witness.mjs:43` imports three exports that do not exist in `src/eproc.mjs`:**
   `import { geometricGrid, makeDriftMixture, makeApproachMixture } from './eproc.mjs'`
   eproc.mjs actually exports: `logsumexp, increments, eprocess, witness`.
   Live import → `SyntaxError: The requested module './eproc.mjs' does not provide an export named 'geometricGrid'`.

2. **Both experiment runners crash on import** (they import `witness` from `../../src/witness.mjs`):
   - `node experiments/xor-loss/run.mjs` → SyntaxError (above)
   - `node experiments/sine-loss/run.mjs` → SyntaxError (above)

3. **Two incompatible same-named `witness()` APIs share the repo:**
   - `src/witness.mjs:55` — `witness(series, claim, opts = {})` — positional claim, **no sigma parameter**
   - `src/eproc.mjs:56` — `witness(series, { claim = "DECREASES", sigma, delta = 0.05 } = {})` — options object,
     sigma **required** (the v0.1.0 pre-registered-sigma discipline, enforced by test NC3)
   The stale copy is actively dangerous: if someone "fixes" its imports naively, it silently produces
   unregistered-sigma witnesses — exactly the peeking the design receipt forbids.

4. **Suite status (precise):** `node --test test/witness.test.mjs` → **7/7 ok** (T1–T4, NC1–NC3).
   The suite exercises `eproc.mjs`'s witness only. Minor separate bug: the `npm test` script
   (`node --test test/`) fails on node v22.23.3 in this environment — the runner tries to resolve
   `test` as a module (ERR_MODULE_NOT_FOUND artifact), independent of the witness.mjs defect.

## Reading

`src/witness.mjs` is a stale earlier generation of the witness that was superseded by the
eproc implementation; its import line rotted while the suite (correctly testing eproc directly)
stayed green. Nothing imports witness.mjs except the two experiment runners — which are the
repo's own demos of "witnessing a training claim."

## Recommended fix (for the owner — nothing touched in this clone)

Point both runners' imports at `./eproc.mjs`'s witness and retire `src/witness.mjs`
(archive-by-rename per fleet doctrine). If witness.mjs's own API is wanted later, it must
re-grow the required-sigma discipline first.

## Connection to the patchwork doctrine

This is PX1b/PX2 in miniature: a specialist cell whose interface rotted relative to its
dependents. The immune layer the canvas experiments validated (format-gate → loud abstain,
never silent) is what was missing at the import boundary — a one-line smoke import in CI
converts this silent rot into loud failure before anything believes a number from these runners.
