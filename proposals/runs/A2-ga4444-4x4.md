## 0. The claim under test

A1's booked finding (`results/a1_pie/RESULTS-ENTRY.md`, 3×3 `pie-minimax`):

> a 1,225-param ReLU net — still a purely *local* board→scores rule with no search —
> absorbs minimax composition to **~0.94 board-disjoint** with **no COMPOSED collapse**,

## 1. Recon (before any measured number) — two repo findings + one scope decision

**[R1] The C export is an INCOMPLETE walk, not the state space.** `gt4444.c` `walk()` prunes
with **`return`** where `continue` belongs (`if (has_won(pos|mv, m2)) return;` inside the
column loop), so its committed 3,338-row `gt4444_ground_truth.txt` is a pruned *sub-walk*.
The repo's own `verify_maxmin.py` reports **161,029 reachable states**; this lane's complete
BFS of the reachable **non-terminal** gravity graph is **139,625** states
(139,625 non-terminal + 21,404 terminal = 161,029 — the two agree exactly). The C's *values*
are exact; only its *enumeration* is incomplete. Recorded as a correction.

**[R2] The repo contains TWO different games.** `ga4444.py` `legal_moves` is **free
placement** (a stone may land in a gap); its reachable non-terminal graph exceeds **8×10⁶**
states (measured, >8M) and its labels are capped at `MAX_PLY=9`. `gt4444.c` is **gravity**
(column drop). They are not the same game and do not share position values.

**Scope decision (frozen).** This lane uses the **gravity game** — the one the repo
strong-solves with complete ground truth — and builds its **own complete enumeration**
(66,297 our-turn non-terminal boards). The free-placement variant is **out of scope** today
(state space >8M, horizon-capped labels) and is named explicitly so no number here is read
as a free-placement result.

**[R3] Sampling frame.** **No sampling.** The gravity our-turn non-terminal space is
enumerable exactly in a session, so the dataset is the **complete** our-turn set (all p0-to-move
non-terminal boards reachable under gravity). Dataset digest recorded with every number.

**Population (measured, recon).** 66,297 our-turn boards; ply histogram
{0:1, 2:16, 4:160, 6:1128, 8:5036, 10:14352, 12:24710, 14:20894};
multi-optimal **47.8%** (set-valued labels matter — A1's lesson carries);

## 4. Splits & variance (frozen)

- **5-fold board-disjoint CV.** Fold `= (fnv1a64(board_bytes) >> 32) mod 5` (high 32 bits —

- **Variance = std across the 5 data folds** (not seeds — the repo showed seed-std ≡ 0).
  **`std == 0` on any gate column → INCONCLUSIVE, never PASS** (rule 2).
- Chance is **computed** per fold per partition (`mean(|opt|/|legal|)`), never assumed.

## 6. FROZEN GATES (measured on the 5-fold CV means; no goalpost migration)

Let `Δ_arm = top1_SIMPLE-B − top1_COMPOSED-B` (positive = composition penalty).

| verdict | condition |
|---|---|
| **BREAKS (A1 does not scale)** | `Δ_linear ≤ 0.05` — the linear arm shows **no** composition penalty at 4×4 with complete ground truth ⇒ the 3×3 "linear collapse" does not carry up; A1's linear half is corrected. |
| **SCALES (A1 replicates)** | `Δ_linear > 0.05` **AND** `Δ_mlp ≤ 0.05` **AND** `top1_mlp_overall ≥ top1_linear_overall + 0.05` ⇒ nonlinear absorbs composition, linear collapses — A1 one rung up. |
