A Cell = { id: number, name: string, dials: {number}, edges: {{dst:number, weight:number}},

qm_bind(reg, name) -> Cell:
  register-or-look-up a cell BY NAME (idempotent). If name already bound, return the SAME
  cell (no new id). Else create Cell{id = reg.nextId, name = name, dials = 16 zeros,
  edges = {}, act = 0, bound = true}; append id to order; byName[name] = id; nextId += 1.
  Return the cell.

qm_link(reg, srcId, dstId, weight?) -> {dst:number, weight:number} | nil:
  The HEARER owns the edge: this creates/updates an edge ON THE DST CELL pointing at srcId
  (an edge is "dst can hear src"). weight defaults to DEFAULT_LINK_W, clamped to [0,1].
  - If either id is unknown -> return nil.
  - If dst already has an edge to src -> update that edge's weight (clamped) and return it.
  - Else if dst has EDGE_CAP (8) edges -> EVICT the lowest-weight edge (coldest stool;
    ties -> the earliest-created of the tied) and reuse that SLOT, then insert.
  - Else append. Return the edge.

getCell(reg, id) -> Cell | nil ;   getCellByName(reg, name) -> Cell | nil
reg.count(reg) -> number  (number of bound cells)   [a method stored on the registry table]

setDial(cell, addr, value) -> number | nil:
  addr must be an integer in [0, NDIALS-1]; otherwise return nil (no store).
  Store clamp01(value); return the stored value.
getDial(cell, addr) -> number | nil:
  integer addr in [0, NDIALS-1] -> stored dial (0.0 if never set). Out-of-range -> nil.

qm_effect(reg, srcId, dstId, activation) -> {delivered:boolean, weight:number, applied:number}:
  "link before effect": delivered ONLY if the DST cell has an edge pointing at srcId.
  - unknown ids, or no such edge -> {delivered=false, weight=0, applied=0} (dropped silently).
  - else: applied = clamp01(activation); dst.act = clamp01(dst.act + edge.weight * applied);
    delivered = true, weight = edge.weight. The edge weight is NOT changed by qm_effect.

qm_tick(cell, leak?) -> {edges:number, act:number}:
  One tick: leak defaults to DEFAULT_LEAK, clamped to [0,1].
  For every edge: weight = clamp01(weight * (1 - leak)).
  cell.act = clamp01(cell.act * (1 - leak)).
  Return {edges = #cell.edges, act = cell.act}.

qm_view(reg, id, kind, arg?) -> number | nil:
  kind == 0 -> cell.act ; kind == 1 -> sum of edge weights (clamped to [0,1]) ;
  kind == 2 -> getDial(cell, arg) ; unknown cell -> nil. Anything else -> nil.
